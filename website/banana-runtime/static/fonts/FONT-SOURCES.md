# Font sources

- `Inter-*.woff2` contains Inter 4.001, identified by `git-9221beed3`
  in the font metadata. The Inter project identifies Inter as a Reserved
  Font Name. [License](https://raw.githubusercontent.com/rsms/inter/9221beed3/LICENSE.txt)
  and [upstream documentation](https://github.com/rsms/inter/blob/9221beed3/README.md).
- `CommitMono.woff2` contains Commit Mono 1.143. Its embedded notice
  credits the 2023 Commit Mono authors.
  [Font license](https://raw.githubusercontent.com/eigilnikolajsen/commit-mono/main/LICENSE-FONT).
- `BananaMath-Regular.woff2` contains Banana Math, a modified KaTeX_Main
  with a distinct primary font name. Its embedded notice supplies the
  copyright holders and the KaTeX_Main Reserved Font Name.
  [Upstream generation script](https://github.com/banana-space/banana/blob/4aaa8bd321dbfe2323c3ffa0d15dd09084ea2cdb/scripts/fonts/banana-math.py)
  and [SIL Open Font License](https://openfontlicense.org/open-font-license-official-text/).
